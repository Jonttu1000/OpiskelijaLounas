## OpiskelijaLounas – CSS-asettelut

| Elementti               | Asettelu | Tarkoitus                                         |
| ----------------------- | -------- | ------------------------------------------------- |
| `.app-layout`           | Grid     | Jakaa pääsisällön kahteen erilevyiseen palstaan   |
| `.restaurants-panel`    | Block    | Järjestää osiot allekkain                         |
| `.panel-heading`        | Flexbox  | Otsikko vasemmalle, suodatus oikealle             |
| `.filter summary`       | Flexbox  | Kuvake ja teksti vierekkäin                       |
| `.restaurant-list`      | Grid     | Ravintolat allekkain, tasaiset välit              |
| `.restaurant-card`      | Grid     | Ravintolan linkkialue ja sydän omiin sarakkeisiin |
| `.restaurant-card-link` | Grid     | Kuvake ja ravintolan tekstit vierekkäin           |
| `.restaurant-icon`      | Grid     | Keskittää kuvakkeen sisällön                      |
| `.restaurant-card-copy` | Grid     | Nimi, osoite ja palveluntarjoaja allekkain        |
| `.details-panel`        | Block    | Sisältöalueet allekkain                           |
| `.restaurant-intro`     | Flexbox  | Ravintolan tiedot vasemmalle, suosikki oikealle   |
| `.view-switcher`        | Flexbox  | Päivän ja viikon painikkeet samalle riville       |
| `.menu-date`            | Flexbox  | Päivämäärä ja aukiolotiedot eri reunoille         |
| `.menu-list`            | Grid     | Ruokakortit allekkain                             |
| `.meal-card`            | Grid     | Numero, ruokatiedot ja hinta kolmeen sarakkeeseen |
| `.meal-content`         | Block    | Ruoan nimi, kuvaus ja merkinnät allekkain         |
| `.tags`                 | Flexbox  | Ruokavaliomerkinnät vierekkäin                    |
| `.week-days`            | Grid     | Viikonpäivät allekkain                            |
| `.week-days summary`    | Flexbox  | Päivätiedot ja nuoli eri reunoille                |
| `.week-meals`           | Block    | Sisältää avattavan päivän ruokakortit             |
